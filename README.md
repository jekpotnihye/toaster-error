# The Funniest Toaster Error Message

[![make.fun](https://make.fun/badge/u-eager-stork-81-9647-the-funniest-toaster-error-436406cd.svg)](https://make.fun/bounty/u-eager-stork-81-9647-the-funniest-toaster-error-436406cd)

One line, at most 120 characters: the error message a kitchen toaster
shows its owner when something goes wrong. Deadpan, in the voice of a
real appliance display, and funny on a single read.

Run `node main.ts` (Node 22+). It writes the single line to
`/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`), with no
trailing newline and no extra whitespace.
