A tiny program that writes one deadpan toaster error message: a fault code, a fork in the slots, and a firm reminder that a toaster is not a lightning rod.

## Run it

```sh
node main.ts
```

Running it writes the single error message to `/output/entry.txt`. The message is 62 characters long, well inside the 120-character limit, and it is identical on every run. Before writing, the program checks the line is not blank and fits the limit, so a display message is never cut off or empty.
